Amazing Art 精品课 · PPT 互动总网页（2026-10-12 Hark）

使用方法
1. 先把压缩包「全部解压缩」，7 个 HTML 必须放在同一个文件夹里。
2. 用 Chrome 或 Edge 双击 00_Amazing_Art_PPT.html，按 F 全屏。断网也能用。

总网页（00）操作 —— 画面上没有任何按钮
- 下一步（动画逐个出现 / 下一页）：鼠标单击、空格、→、↓、PageDown、滚轮向下
- 上一页：←、↑、PageUp、鼠标右键、滚轮向上
- 跳页：输入页码数字后按 Enter（例如 7 Enter）
- 带辉光的图片可点击，进入互动页：
  第3页三张展厅卡 → VR 美术馆对应展厅；第4页 → 3D 单词球；第7页 → 浙江艺术地图；
  第8页 → 画廊任务；第10页 → 越剧展厅；第12页六个圆形展馆 → 作业页对应展馆卡片
- F 全屏 · B 黑屏 · M 音效开关 · H 显示/隐藏快捷键说明

子页面（01–06）
- 鼠标移到画面顶部（上方绿条下沿）→ 工具栏滑出：左侧「‹ PPT」返回总网页对应页，右侧 A− / A+ 调整全局字号（会记住）、全屏键。
- 01 VR：鼠标靠左边缘 → 作品列表抽屉滑出。
- 02 单词球：靠左边缘 → 词库；靠右边缘 → 词条详情；点单词时详情自动滑出，点球的空白处收起。
- 03 地图：靠右边缘 → 信息栏；点头像时自动滑出，点地图空白处收起。
- 字体：Times New Roman 为主、Arial 为辅；正文 24–28、标题 32–40（按 1920×1080 设计尺寸）。

导航（互动页在 PPT 里面打开，全屏不会退出）
- 点带金色辉光的图片：互动页在总网页里以全屏图层淡入打开（地址不变，全屏保持）。
- 移动鼠标 → 金色图标出现，约 2 秒后自动隐去：
  左上角「返回 PPT」；左下角 ‹ 上一个互动页、右下角 › 下一个互动页（按 01→06 顺序）。
- 返回 PPT：左上角返回图标、子页面顶栏「‹ PPT」、Esc 或 Backspace。返回后停在原来的那一页、原来的动画步骤。
- PPT 页面上移动鼠标 → 左右两侧出现金色 ‹ › 箭头，点击 = 上一步 / 下一步（与键盘、单击相同）。
- 互动页里的全屏键会切换整个 PPT 的全屏。

Navigation (interactive pages open inside the PPT, so fullscreen is never lost)
- Click a gold-glowing picture: the interactive page fades in as a full-screen layer inside the deck (address unchanged, fullscreen kept).
- Move the mouse -> gold icons appear and fade out after about 2 seconds:
  top-left "Back to PPT"; bottom-left < previous page, bottom-right > next page (order 01 -> 06).
- Back to the slides: the top-left back icon, the "< PPT" button in the page's top bar, Esc or Backspace.
  The deck returns to the same slide and the same animation step.
- On the slides, move the mouse -> gold < > arrows appear at the left/right edges: previous / next step.
- The fullscreen button inside an interactive page toggles fullscreen for the whole deck.
